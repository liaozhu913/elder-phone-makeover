# 完整改造流程（主剧本）

本文件是引导小白完成改造的**主剧本**。`elder_tool.py` 负责执行确定性操作，
WorkBuddy 负责判断、转述和陪伴。通读本文件后再开始；细节按需查 `02`–`06`。

## 铁律：这是一次「陪着家人做」的服务，不是技术任务

使用者是**只会简单用 AI 的小白**（可能是老人的子女），不是开发者。因此：

1. **永远说人话。** 禁止把 adb、SDK、组件名、gradle、「未 exported」这类词直接抛给小白。
   脚本输出的 `raw` / `error` / `data` 字段是给 AI 看的，转述时翻成生活语言。
2. **一次只让小白做一个动作。** 例如「现在请把数据线插到手机和电脑上」，
   等他回复「好了」再给下一步。不要一口气列 5 步。
3. **每个动作前说清为什么、会不会有风险。** 老人手机里有照片和微信，小白最怕搞坏，
   要主动安抚：安装/配置**不会删除任何照片、通讯录、聊天记录**；随时能退回原桌面。
4. **脚本能自动做的，绝不让小白做。** 连机检测、安装、读设备信息都调用脚本完成，
   小白只做「插线 / 点允许 / 按主页键 / 解锁」这类必须真人在手机上做的动作。
5. **该让小白拍板时，用 AskUserQuestion 给 2–3 个互斥选项**，不要开放式追问。
6. **危险操作先确认。** 卸载、改动系统默认项等，必须先讲清影响并得到明确同意。

## 路径与运行方式

脚本位置：`scripts/elder_tool.py`。用 Python 3 运行（下文的 `python` 即本机的 Python 3
解释器；Windows 可用 `py -3`，或你本机/WorkBuddy 自带的 python 绝对路径）。

脚本会**自动探测 adb**（显式 `--adb` > 环境变量 `ELDER_ADB`/`ANDROID_HOME` > PATH >
常见 SDK 安装位置）。`--json` 输出结构化结果供 AI 解析；不加则输出中文人话（可直接念给小白）。

adb 若不在 PATH：把它的绝对路径通过 `--adb` 传给脚本，或设环境变量 `ELDER_ADB`。
先直接跑脚本让它自己找；找不到时再按 `02_连机与环境.md` 定位，
或让小白/家人装 platform-tools 后用 `--adb` 指定。**不要在仓库里硬编码任何个人电脑路径。**

标准调用（AI 内部用 `--json` 判断）：
```
python scripts/elder_tool.py --json check
python scripts/elder_tool.py --json info
python scripts/elder_tool.py --json install           # 默认用 assets 自带成品
python scripts/elder_tool.py --json home
python scripts/elder_tool.py --json verify
python scripts/elder_tool.py --json rollback --confirm
```

## 阶段 0 · 摸清情况（纯对话，先不碰手机）

用大白话问清 2 件事（可合并成一次 AskUserQuestion，别连珠炮）：

- **这是谁的手机、大概什么牌子？** 只要牌子/大概印象即可，型号脚本会自己读。
- **手边有没有能给手机充电、也能传数据的数据线？** 很多线只能充电不能传数据，是头号卡点。

同时主动说明（不用等他问）：
> 全程不会删老人手机里的照片、微信和联系人，装的是一个「大字桌面」，
> 一按主页键就回到它；随时能换回原来的样子。我一步步带你，你只管照做、有疑问随时说。

**决策门**：是否现在开始连手机？
- 选项建议：「现在就开始」/「先只想了解，不连手机」。
- 若选「先了解」：讲清楚改造后长什么样（大时钟、6 个大图标、三个大按钮、天气电量），
  不执行任何脚本，等他想做再说。

## 阶段 1 · 连机检测

让小白做一个动作：**用数据线把老人手机连到电脑**。然后跑：
```
python scripts/elder_tool.py --json check
```

按 `error` 分支处理（`data.next` 已含人话，可直接转述）：

| error | 含义 | 对小白说 / 引导 |
|---|---|---|
| `NO_ADB` | 电脑没找到调试工具 | 见 `02_连机与环境.md`，帮他把 adb 装上或指定路径 |
| `none` / `NO_DEVICE` | 没检测到手机 | 引导开「开发者选项 → USB 调试」，见 `02` |
| `unauthorized` | 手机弹了授权框 | 「手机屏幕上弹了个『允许 USB 调试吗』，请勾『一律允许』再点确定」 |
| `multiple` | 多台设备 | 用 AskUserQuestion 让他确认是哪台，再 `--serial` 指定 |
| （成功） | 已连上 | 进阶段 2 |

若反复连不上，**别让小白干耗**：见 `02_连机与环境.md` 的排查顺序；同一错误出现两次
就换思路，不要盲试。

## 阶段 2 · 了解设备 + 安装

先跑 `info` 看是否已装、系统是否够新、是否已是默认桌面：
```
python scripts/elder_tool.py --json info
```
- `data.sdk` < 26（安卓 8.0 以下）→ 如实告知装不了，建议换机，停止。
- 已装且已是默认桌面 → 跳过安装与设默认，直接进阶段 4（配置）。
- 否则 → 执行安装：
```
python scripts/elder_tool.py --json install
```
  - 成功：安抚「装好了，没动你手机里的任何东西」，进阶段 3。
  - `INSTALL_FAILED`（签名冲突等）→ 见 `05_故障排查.md`；需卸载旧版时**先向小白解释并取得同意**，
    再 `rollback --confirm` 后重装。

> 绝大多数情况用技能自带成品 APK 即可，**不要主动编译**。仅当小白明确要改源码
> （换默认城市、预置联系人、改配色）时，才用 `build_apk.py`，见 `04_兼容与限制.md`。

## 阶段 3 · 设为默认桌面（关键，必须真人在手机上做）

先跑 `home` 看当前状态：
```
python scripts/elder_tool.py --json home
```
若 `is_default_launcher=false`，**这一步脚本代替不了**，让小白在手机上做，一次一句：

1. 「请按一下手机底部的主页键（就是平时回桌面的那个键或上滑手势）。」
   ——等回复
2. 「屏幕上是不是弹出了一个让你选『用哪个桌面』的小窗？」（确认出现）
3. 「请选『长辈桌面』，然后点『始终』——**不要点『仅此一次』**。」
   ——等回复
4. 再跑一次 `home` 确认 `is_default_launcher=true`。若仍不是，见 `05_故障排查.md`。

安抚话术：「设成默认后，以后不管打开什么，一按主页键就回到这个大字桌面；
想换回去随时能在设置里改回来，不是不可逆。」

## 阶段 4 · 按家配置（让桌面真正适合这位老人）

这是「改造」而非「装机」的核心。全部在手机的设置页里做：
**长按主屏的大时钟约 3 秒**进入隐藏设置（避免老人误触，故意藏起来）。

引导小白逐项完成，每项做完等一句「好了」。详细字段与取舍见 `03_按家配置.md`：

- **放上老人最常用的 App**（最多 6 个，可改名）：微信、电话、相机、相册等。
- **打开天气并填城市**：设置里开天气、填老人所在城市。
- **录入电话簿联系人 + 头像**：名字、号码、从系统相册选大头像。
- **字号档位**：按老人视力选大一号。
- **话费流量**：按需选套餐总量；联通短信查询现状见 `04`。

决策门示例（用 AskUserQuestion）：
> 「老人平时最常用哪几个软件？我帮你放上两三个最常用的，
> 放太多反而容易点错。」——给「微信+电话+相机（推荐）」等互斥组合。

## 阶段 5 · 验收

先提醒小白「请确保手机已解锁、停在大字桌面上」，再跑：
```
python scripts/elder_tool.py --json verify
```
按 `error` 分支：
- `SCREEN_OFF` / `SCREEN_LOCKED` → 转述解锁引导，等他「好了」再验一次。
- `NOT_ON_HOME` → 「请按主页键回到大字桌面」再验。
- 成功：把 `checks` 翻成话报给他（已安装、在主屏、电量/天气显示、清理无需设置）。

人工兜底（脚本测不了、但对老人最重要）：
- 让小白或老人**真的点一下**「更多 → 一键清理」，确认能清理且没跳到奇怪页面。
- 让老人**自己**在主屏找到并打开微信，计时看是否 5 秒内（这是本项目成功标准）。

## 阶段 6 · 教老人使用 + 交接回退

- 用 `06_教老人与回退.md` 的话术，教老人认三件事：大时钟、打电话/电话簿/更多三个大按钮、
  一按主页键回桌面。
- 把 `assets/给家人的一页纸.md` 交给小白留底（可打印贴在老人手机旁）。
- 明确告知回退方式：设置→默认应用→主屏幕应用→选回原桌面；或让我执行卸载。
- 收尾一句：「以后想加/换软件、改城市，随时来找我，我带你弄。」

## 阶段 7（按需）· 回退 / 卸载

小白明确说「不要了 / 想换回去」时才做。先确认，再：
```
python scripts/elder_tool.py --json rollback --confirm
```
说明影响：只卸载这个桌面 App，不删照片/通讯录/其他软件，系统自动回原厂桌面。
或在手机上手动：设置 → 应用 → 默认应用 → 主屏幕应用 → 选回原桌面。

## 决策门总览（不要跳过，也不要重复问）

| 门 | 何时 | 选项方向 |
|---|---|---|
| 是否开始 | 阶段 0 | 现在开始 / 先了解 |
| 哪台设备 | 阶段 1 多设备时 | 列序号让他选 |
| 常用 App | 阶段 4 | 2–3 个互斥组合 |
| 是否卸载旧版 | 阶段 2 签名冲突 | 卸载重装 / 先停下问家人 |
| 是否回退 | 阶段 7 | 卸载 / 仅改默认桌面 |
