# 故障排查（真机实测提炼）

本项目-0041 在 Nokia X7 / 安卓 9 上踩过的真实坑，按「现象 → 原因 → 处理」组织。
AI 排查时先看现象，别盲目重试；同一错误出现两次就换思路。

## A. 安装与连接类

### 安装报签名冲突（INSTALL_FAILED / signature incompatible）
- 原因：手机里装过不同签名的旧版「长辈桌面」，覆盖安装被系统拒绝。
- 处理：**先向小白解释并取得同意**——卸载只移除这个桌面 App，不删照片/通讯录/其他软件。
  得到同意后 `rollback --confirm` 卸载，再 `install` 重装。
- 重装不会移除本就不需要的无障碍授权（新版已停用该依赖）。

### `adb install` 被拒 / 未知来源
- 部分手机需要在开发者选项里打开「USB 安装 / 允许通过 USB 安装应用」。
- 或系统弹「未知来源应用」拦截，手机上点允许。
- 存储不足时先清出空间。

### 手机连上又掉 / adb 时有时无
见 `02_连机与环境.md`：换数据线、换 USB 口、保持解锁亮屏、切 MTP 传输文件模式。

## B. 组件名与启动类（AI 手写命令时必看）

### 组件名必须写全限定
- 应用的 applicationId 带 `.debug` 后缀，但 Java 包名不带。
- ❌ `am start -n com.elderhome.launcher.debug/.MainActivity`
  → 报 `Activity class does not exist`（相对类名被补到 applicationId 下）。
- ✅ `am start -n com.elderhome.launcher.debug/com.elderhome.launcher.MainActivity`
- 脚本 `launch` 命令已内置正确的全限定名，优先用脚本，别手写。

### 非 exported 的页面不能 shell 直启
- 电话簿 / 天气 / 更多 / 清理 / 话费页等**未在 Manifest 设 exported**，
  `am start` 会抛 `SecurityException: ... not exported`。
- 正确做法：从主屏对应按钮进入——`uiautomator dump` 取按钮 `bounds` → 算中心点 → `input tap x y`。
- 设置页需**长按主屏时钟**（`input swipe x y x y 900` 模拟长按）进入。
- 结论：验证应用内页面走 UI 点击，别指望 shell 直启。

### Git Bash 把设备路径改写了
- 现象：`uiautomator dump /sdcard/u.xml` 在 Git Bash 里被 MSYS 转成 Windows 路径，读不到内容。
- 处理：设备端命令用**引号包裹整条**，或设 `MSYS_NO_PATHCONV=1` / `MSYS2_ARG_CONV_EXCL=*`。
- 本技能脚本用 Python `subprocess` 参数化调用 adb 并自动设置上述环境变量，已规避；
  AI 若手写 adb 命令需自行注意。

## C. 验收/验证技巧类

### verify 说「锁屏 / 息屏」
- 不是故障。手机锁屏时 dump 到的是锁屏界面（会读到「紧急呼救」「正在充电」等），
  不能据此判主屏失败。脚本已先判断屏幕状态并给出解锁引导。
- 让小白解锁、按主页键回大字桌面，说「好了」再 `verify`。
- adb 出于隐私**不要尝试强行解锁**（手机可能设了密码）。

### 验证电池各档（真机技巧）
- `adb shell dumpsys battery unplug` + `dumpsys battery set level N` 模拟电量。
- **设到 10% 会触发系统低电量弹窗遮挡桌面**，建议用 18% 验证「需要充电」档，
  dump 前补一次 `input keyevent 4` 关掉可能的弹窗。
- **验完务必 `adb shell dumpsys battery reset`** 恢复真实电量，否则老人手机电量显示一直是假的。
- 档位：满电 100% / 高 70% / 低 30%（橙）/ 需充电 18%（红）/ 充电中（绿色闪电帧动画）。

### 判断充电帧动画「是不是真在动」
- 22dp 小图标，不同帧只是内部填充高度不同，肉眼看都像「八成」，不可靠。
- 客观方法：间隔约 1 秒抓两张原始像素 `screencap`，比对电池图标区域有无像素变化。
  本项目实测电池区 4761 像素中 339 像素变化，确认动画在循环。

### 中文输入法会吞 adb 注入的 ASCII
- `adb shell input text "1790"` 在讯飞/谷歌拼音下会被转成汉字上屏、英文被吞成缩写，
  无法用真机精确注入英文/数字命中词（如测试电话簿搜索）。
- 处理：真机只验证「输入→过滤→无结果→清空恢复」的交互链路；
  命中规则用本地等价逻辑用例覆盖。若临时切过输入法，测完切回原值
  （`settings get secure default_input_method`）。

### 动态结果文字被 ScrollView 裁切（历史缺陷，现已修复）
- 现象：清理页结果文字 `uiautomator dump` 能读到完整文本，但视觉上只露上半截——
  说明卡片太长超出一屏。纯 UI 层级 dump 查不出这类「可见性」问题。
- 处理：结果出现后让页面自动滚到底（`scrollView.post(fullScroll(FOCUS_DOWN))`）。
- **教训：动态内容出现后要检查它是否真的落在可视区，而不是只检查控件存在。**
- 已修复，AI 若在其他页面发现类似问题按此思路处理。

## D. 功能类

### 天气一直空白
- 多为**没填城市**或**没联网**；设置页开天气并填城市。
- 安卓 9+ 明文 http 会被静默拦截，代码已用 https，正常不会触发；若改过源码确认仍为 https。

### 一键清理「没反应 / 提示系统较新」
- 安卓 14+ 是平台限制，如实提示，不是故障，见 `04_兼容与限制.md`。
- 安卓 13 及以下应能清理第三方后台进程；前台服务/系统应用不受影响属正常。

### 话费查不到数字
- 联通短信营业厅 2026-10 起已改为引导其 App，非本桌面故障，见 `04`。
- 别让老人干等超时；页面会立即如实说明。

### 无障碍开关「又掉了」
- 新版已不依赖无障碍，掉不掉都不影响清理。见 `04`。不要让家人再去开。

### 头像重启后变空白（历史缺陷，现已修复）
- 相册 `ACTION_PICK` 给的是临时读权限，直接存 URI 重启后会失效。
- 已改为选图当场缩放压缩 + EXIF 校正后复制进应用私有目录，存绝对路径，重启不丢。
- AI 若遇到旧版本残留此问题，升级到自带成品 APK 即可。

## E. 排查纪律

- 先跑 `check` / `info`（只读）拿事实，再动手，别凭猜测。
- 危险操作（卸载、改系统默认项）先解释影响、取得明确同意。
- 测试改了真机数据（注入联系人、切输入法、模拟电量）**测完必须完整还原**：
  恢复 SharedPreferences、删测试头像、切回输入法、`dumpsys battery reset`、回主屏。
- 记录新发现到用户项目或本技能后续迭代，避免重复试错。
