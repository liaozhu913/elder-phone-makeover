# 连机与环境（数据与授权）

小白最容易卡在「连不上手机」。按本文件顺序排查，一次只让小白做一个动作。

## 头号卡点：数据线只能充电、不能传数据

现象：手机插上电脑有充电反应，但 `check` 一直 `NO_DEVICE`。
很多随赠线只有供电没有数据线芯。**换一条确定能传数据的线**（能往电脑拷照片的那种），
或换一个电脑 USB 口（优先机箱后面的口 / 不要用无供电的 USB Hub）。

## 让小白打开 USB 调试（用大白话一步步说）

不同牌子菜单名字略有差别，让小白找关键词即可，别念一堆路径让他慌：

**第一步，打开「开发者选项」（大部分安卓手机都要先做一次）**
1. 打开手机「设置」。
2. 找到「关于手机」（有的在「系统 → 关于手机」）。
3. 找到「版本号」（或「内部版本号」），**连续快速点 7 下**。
4. 可能让输入锁屏密码，输入即可。
5. 提示「您已处于开发者模式」就成了。

**第二步，打开「USB 调试」**
1. 回到「设置」，找「开发者选项」（华为/荣耀可能在「系统和更新」里，
   小米在「更多设置」里，OPPO/vivo 在「其他设置」里，三星在设置最底部）。
2. 找到「USB 调试」，打开。
3. 弹「允许 USB 调试吗」时点「允许」。

**第三步，连电脑**
1. 用数据线把老人手机连到电脑。
2. 手机通知栏可能出现「正在通过 USB 充电 / 传输文件」——
   若有「传输文件(MTP)」选项，选它更稳。
3. 手机弹出「允许 USB 调试吗？」→ **勾上「一律允许使用这台计算机进行调试」**再点「允许/确定」。
4. 回到对话跟我说「好了」，我重新检测。

各品牌「开发者选项」常见位置（供 AI 提示小白，不要整段念给他）：

| 品牌 | 开发者选项位置 |
|---|---|
| 华为 / 荣耀 | 设置 → 系统和更新 → 开发人员选项 |
| 小米 / Redmi | 设置 → 更多设置 → 开发者选项（MIUI 需先连点「我的设备 → 全部参数 → MIUI 版本」） |
| OPPO / 一加 | 设置 → 其他设置 → 开发者选项（先连点「关于本机 → 版本信息 → 版本号」） |
| vivo | 设置 → 系统管理 → 开发者选项（先连点「系统管理 → 关于手机 → 版本信息 → 软件版本号」） |
| 三星 | 设置最底部 → 开发者选项（先连点「关于手机 → 软件信息 → 编译编号」） |
| 原生 / Nokia / 摩托罗拉 | 设置 → 系统 → 关于手机 → 连点版本号；开发者选项多在「系统」内 |

## adb 找不到时（`error: NO_ADB`）

脚本已按「显式 > 环境变量 > PATH > 工作区工具链 > 常见 SDK 位置」自动找。仍找不到时：

1. 看 `check` 的 `data.adb_path` 是否存在；`NO_ADB` 说明都没命中。
2. 把 adb 的绝对路径传给它（下面路径请换成你自己电脑上的实际位置）：
   ```
   python scripts/elder_tool.py --adb "C:/你的platform-tools目录/adb.exe" --json check
   ```
3. 让家人装一个最小的「Android SDK Platform-Tools」
   （Google 官方免费，解压即用，无需 Android Studio）：
   - 下载地址搜「SDK Platform Tools」，选对应系统；
   - 解压后把目录里的 `platform-tools` 路径通过 `--adb` 指给脚本，或加进 PATH。
4. 也可设环境变量 `ELDER_ADB` 指向 adb 可执行文件，脚本会自动读取。

## 授权弹窗没弹 / 点了没用（`error: unauthorized`）

- 手机锁屏时可能不弹授权框：**先解锁手机**再插拔一次数据线。
- 换过电脑或线，需要重新授权。
- 若始终不弹：开发选项里点「撤销 USB 调试授权」后重新连，一般就会再弹。
- 授权时一定勾「一律允许」，否则每次都要点，老人会烦。

## 连上又掉线 / 时有时无

- 换数据线、换 USB 口（见开头）。
- 手机息屏或锁屏可能导致调试断开：让小白保持手机解锁、屏幕亮着。
- 部分手机「仅充电」模式会自动断调试：通知栏把 USB 用途切到「传输文件(MTP)」。
- 跑 `adb devices -l` 看状态：`device`=正常，`unauthorized`=没授权，`offline`=重插。

## 权限与隐私边界（重要，主动向小白说明）

- 安装、配置**不会读取/上传**老人的照片、通讯录、聊天记录、短信内容到任何地方。
  （长辈桌面本身除天气外不联网；话费查询才会用到短信权限，且需当场授权。）
- USB 调试是本机与手机之间的通道，用完可以让小白在开发者选项里关掉，更安心。
- `check / info / home / verify` 全只读，不改手机；`install` 只覆盖安装本应用；
  只有 `rollback` 会卸载，且必须先确认。
