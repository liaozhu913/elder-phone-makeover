# 兼容与限制（先把话说明白）

改造前主动告诉小白这些边界，避免期待落空。**宁可事先说清，不要事后甩锅。**
本节内容来自项目-0041 的真机实测（Nokia X7 / 安卓 9），换机型时按实际复核。

## 设备门槛

| 项 | 要求 | 说明 |
|---|---|---|
| 系统 | 安卓 8.0（API 26）及以上 | 更低装不了；`info` 命令会自动判断并提示 |
| 一键清理可用 | 安卓 13（API 33）及以下 | 安卓 14+ 系统禁止第三方结束他人进程，见下 |
| 数据线 | 能传数据（不只是充电） | 头号卡点，见 `02` |
| 是否需 root | **不需要** | 全程普通 adb 调试即可 |
| 是否需无障碍 | **不需要**（已彻底移除依赖） | 见下「无障碍」 |

## 一键清理：能力边界（重要）

- 用普通权限 `KILL_BACKGROUND_PROCESSES` 结束**第三方 App 的后台进程**，
  **安装即授予、不弹窗、不会掉线**，家人一次都不用帮忙设置。
- 只清理用户自己装的软件（抖音、今日头条等娱乐类）；**电话、短信、系统功能、
  桌面自身一律不动**；正在放歌、导航等前台服务也不会被打断。
- **安卓 14 及以上**：系统限制第三方结束他人进程，页面会如实提示
  「这台手机系统较新，不允许自动清理后台，可以让家人在手机设置里手动关」，
  不会做有害动作、也不会引导去开任何开关。这是平台限制，不是故障。
- 结果用定性文案（「清理好啦，后台偷跑的软件都关掉了」），不虚报「杀了几个」——
  第三方 App 读不到别的进程信息，做不到精确计数。

## 无障碍：为什么会「经常掉」，现在为什么不用管了

历史问题，供解释，不必操作：

- 旧版本曾用无障碍服务模拟「划走最近任务卡片」来清理，但真机发现两大致命问题：
  1. 任何一次「强制停止」（用户在设置里点，或手机自带省电/内存清理组件清后台）
     都会把无障碍授权**永久移除**，重新打开 App 也救不回。结果就是家人刚开完又掉、
     要反复设置——对老人极不合理。
  2. 划卡片/点「全部清除」会把桌面自己的任务一起清掉，卡在系统最近任务页。
- 因此新版**彻底去掉对无障碍的依赖**。旧手机系统设置里若还残留这个开关项，
  说明已改为「这个开关已经不用了……保持关闭即可」，**不用管它、也不用再打开**。
- 结论：清理功能与无障碍开关**掉不掉都无关**，不用再让家人反复去开。

## 话费和流量：运营商现状（2026-10 实测）

| 项 | 现状 | 对老人怎么处理 |
|---|---|---|
| 流量 | **本机可算、可靠** | 设一次套餐总量后显示「已用 X，还剩 Y」；不依赖运营商 |
| 话费 | 只能问运营商，没有本地方案 | 短信/USSD/运营商软件三选一 |
| 中国联通 | 短信营业厅**已不再返回数字**，只回「请跳转到中国联通 APP 查询」 | 页面如实提示；装了联通 App 会出现大按钮；可打 10015 投诉要求恢复（有先例） |
| 中国移动 / 电信 | 短信查询仍有效（本机无卡未实测） | 发指令后自动提取余额/流量 |

- 短信查询免费、无需登录，但**首次要授权短信权限**；部分厂商（如 Nokia/FIH ROM）
  还有二次弹窗拦截，需家人用 adb 预设一次 `appops set ... SEND_SMS allow`（换机/重装后要重设）。
- 话费「查不到数字」是运营商侧变更，**不是本桌面坏了**，务必向小白讲清，别让他以为没装好。

## 天气

- 数据来源中国天气网，免费免 Key，需手机联网；安卓 9+ 用 https（明文 http 会被系统静默拦截）。
- 断网/未填城市时显示「暂时看不了」，不会崩溃。
- 一周预报按日聚合，数据来自页面 `hour3data` 滑动窗口，头尾不完整的一天会跳过。

## 权限清单（都是按需申请，默认保守）

| 权限 | 用途 | 何时申请 |
|---|---|---|
| INTERNET | 仅天气 | 安装时（普通权限，无弹窗） |
| CALL_PHONE | 电话簿二次确认后直接拨号 | 首次拨号时 |
| CAMERA | 手电筒闪光灯 | 首次点手电筒时 |
| READ_CALL_LOG | 未接来电提示 | 设置中开启时（默认关闭） |
| SEND_SMS / READ_SMS | 话费流量查询 | 首次点「查一下」时 |
| KILL_BACKGROUND_PROCESSES | 一键清理 | 安装时（普通权限，无弹窗） |
| QUERY_ALL_PACKAGES | 枚举已装软件以清理 | 安装时 |

**不申请**：定位（天气用固定城市）、读取系统通讯录（电话簿手动录入）、录音。
除天气外无联网行为，无数据上传、无统计遥测。

## 回退能力

- **永不禁用原厂桌面**，随时能改回：设置 → 应用 → 默认应用 → 主屏幕应用 → 选回原桌面。
- 卸载本桌面：手机自动回原厂桌面；`rollback --confirm` 可经 adb 卸载。
- 卸载只移除这个桌面 App，**不删老人手机里的照片、通讯录、聊天记录和其他软件**。
- 配置弄乱：设置页「恢复默认」一键还原。

## 机型差异提醒

- 当前真机经验只在 **Nokia X7 / 安卓 9** 完整验证过。
- 其他机型需按实际复核：默认桌面选择器的样式与位置、包可见性（安卓 11+）、
  安卓 14+ 清理能力、厂商 USB 调试/USB 安装的开关位置、厂商短信二次确认弹窗。
- 遇到与本文档不符的表现，以真机为准，记录到用户项目或本技能后续迭代。
